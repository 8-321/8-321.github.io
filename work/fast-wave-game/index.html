OVERVIEW / 概述01

让声音，变成看得见的界面。

快放电波游戏视觉设计，包含标题页、玩法说明、游戏内界面与一套可复用的 UI 组件。

深蓝底、青蓝霓虹、声波网格与玻璃拟态按钮，把「声音」变成可见的界面材质。

PROCESS / 过程

从氛围到组件。

  1. 01

    情绪板

    收集声波、示波器、霓虹与玻璃材质，确定冷暖对比。

  2. 02

    标题页

    用超大字标与声波环形阵列建立第一眼的节奏感。

  3. 03

    游戏内 HUD

    把分数、提示、摇杆与音量控件放进同一套发光边框。

  4. 04

    组件拆分

    把按钮、摇杆、滑块与弹窗拆成可复用组件。
